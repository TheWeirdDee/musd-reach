The six review findings are addressed in the local working tree. These changes have **not

## Fixes

- The tracker confirms settlement only after a successful pending-settlement read. Loading
  and failed reads show an unknown payout state, even after the return message was consumed.
- Transfer derivation removes orphaned origins, refreshes all origin fields after reinclusion,
  and drops a signature cached for a different origin transaction. Reorg deletion and cursor
  rewind are atomic, so a failed replacement RPC request cannot lose the rewind.
- History uses an origin-timestamp and transfer-ID cursor across both chains. A boundary
  inside a block skips no records. Migration 002 rewinds existing cursors to backfill timestamps.
- The history page loads older pages and deduplicates transfers across page boundaries.
- The README now links the hosted app and API and describes the API's cold start.
